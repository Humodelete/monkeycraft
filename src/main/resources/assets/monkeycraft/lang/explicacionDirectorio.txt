Este es el directorio para poner los nombres en distintos idiomas

- en_us -> Ingles (Estados unidos)
- es_es -> Español (España)

Lista de otros posibles idiomas: https://github.com/PandaDevOfficial/Minecraft-All-Lang

Estructura de los nomres:

"[elemento].[id_mod].[nombre_interno]":"[nombre_legible]"

+ elemento -> Tipo de elemento que se va a traducir
+ id_mod -> El id del mod (en este caso monkeycraft)
+ nombre_interno -> El nombre que se le ha dado al item al registrarlo en MonkeyItems.java (Ejemplo: Línea 14 a la hora de
    escribir esta nota, el nombre interno es el string que se encuentra al inicio del parentesis en
    ITEMS.register("monkey_skull",() -> new Item(new Item.Properties())). En este caso sería monkey_skull)
+  nombre_legigle -> El nombre que ves dentro del juego al poner el raton por encima o equiparlo
